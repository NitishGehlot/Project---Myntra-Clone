
# 🛍️ Myntra Clone Website

This is a front-end clone of the Myntra e-commerce website created using **only HTML and CSS**. It replicates the basic layout and design of the original site as part of my practice in responsive web design.
---

## 💡 Features

- 🖥️ Responsive layout inspired by the Myntra website  
- 🧥 Product grid section  
- 🎨 Stylish homepage banner  
- 📱 Mobile-friendly design with media queries  
- 📌 Navbar and basic navigation structure

---

## 🚀 Technologies Used

- ✅ HTML5  
- ✅ CSS3
